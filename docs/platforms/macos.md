# What is it ?

[Ember Scanner](https://github.com/jjcazau/EmberScanner) is an open source software that ingest and distribute audio files generated by various software-defined radio recorders. Its interface tries to reproduce the user experience of a real police scanner, while adding its own touch.

You can listen to [Ember Scanner](https://github.com/jjcazau/EmberScanner) on any modern browsers using the integrated web app.

# Recorders compatibility

[Ember Scanner](https://github.com/jjcazau/EmberScanner) works with any radio recorder, as long as they can create audio files separated by conversations or transmissions.

Here is a list of recorders known to work with [Ember Scanner](https://github.com/jjcazau/EmberScanner):

| Recorder                                                       | API | Dirwatch |
| -------------------------------------------------------------- | --- | -------- |
| [Trunk Recorder](https://github.com/robotastic/trunk-recorder) | X   | X        |
| [RTLSDR-Airband](https://github.com/szpajder/RTLSDR-Airband)   |     | X        |
| [SDRTrunk](https://github.com/DSheirer/sdrtrunk)               |     | X        |
| [voxcall](https://github.com/aaknitt/voxcall)                  | X   |          |
| [ProScan](https://www.proscan.org/)                            |     | X        |
| [DSDPlus Fast Lane](https://https://www.dsdplus.com/)          |     | X        |

# Quick start

ALWAYS DOWNLOAD THE LATEST VERSION OF [EMBER SCANNER](https://github.com/jjcazau/EmberScanner) FROM ITS OFFICIAL REPOSITORY AT **[HTTPS://GITHUB.COM/JJCAZAU/EMBERSCANNER](https://github.com/jjcazau/EmberScanner)**. PRECOMPILED VERSIONS ARE LOCATED UNDER THE [RELEASES TAB](https://github.com/jjcazau/EmberScanner/releases).

1. Make sure you have the latest version of [Ember Scanner](https://github.com/jjcazau/EmberScanner).

2. Extract the contents of the archive somewhere on your computer. The configuration file and the database file will be created in this same folder.

        rdio@macos ~ % mkdir ember-scanner
        rdio@macos ~ % cd ember-scanner
        rdio@macos ember-scanner % unzip \
        > ~/Downloads/ember-scanner-macos-arm64-v7.0.0.zip
        Archive:  /Users/rdio/Downloads/ember-scanner-macos-arm64-v7.0.0.zip
          inflating: ember-scanner
          inflating: ember-scanner.pdf

3. Run the executable.

        rdio@macos ember-scanner % ./ember-scanner

        Ember Scanner v7.0.0
        ----------------------------------
        2022/12/19 08:38:06 server started
        2022/12/19 08:38:06 main interface at http://macos.local:3000
        2022/12/19 08:38:06 admin interface at http://macos.local:3000/admin

4. Access the administrative dashboard to finalize the configuration.

> _Note that the default password is **ember-scanner**_

![admin dashboard login](../images/admin-login.png?raw=true)\

5. Configure your [Ember Scanner](https://github.com/jjcazau/EmberScanner) instance.

![admin dashboard todos](../images/admin-todos.png?raw=true)\

# Advanced customizations

## Listening on an alternate port

Here we want our [Ember Scanner](https://github.com/jjcazau/EmberScanner) instance to listen for connections on the standard HTTP port.

        rdio@macos ember-scanner % ./ember-scanner --listen :80

        Ember Scanner v7.0.0
        ----------------------------------
        2022/12/19 08:48:03 server started
        2022/12/19 08:48:03 main interface at http://macos.local
        2022/12/19 08:48:03 admin interface at http://macos.local/admin

## Listening on a SSL port

It is recommended to share your [Ember Scanner](https://github.com/jjcazau/EmberScanner) instance over the internet by listening to an SSL port.

You can use your own SSL certificates that match your domain name with `-ssl_cert_file` and `-ssl_key_file`. If your certificate comes with an intermediate CA certificate, simply add its contents to the standard certificate file.

        rdio@macos ember-scanner % ./ember-scanner \
        > -listen :80                            \
        > -ssl_cert_file mycert.crt              \
        > -ssl_key_file mykey.key               \
        > -ssl_listen :443

        Ember Scanner v7.0.0
        ----------------------------------
        2022/12/19 08:50:58 server started
        2022/12/19 08:50:58 main interface at http://macos.local
        2022/12/19 08:50:58 main interface at https://macos.local
        2022/12/19 08:50:58 admin interface at https://macos.local/admin

If you don't want to worry about SSL certificates, you can use the built-in Let's Encrypt auto-cert feature. This requires that you have both port 80 (HTTP) and port 443 (HTTPS) open to the world. Also, your domain name should point to your IP address where [Ember Scanner](https://github.com/jjcazau/EmberScanner/) is running. The advantage of this approach is that everything is done automatically, no certificate request, no certificate renewal.

        rdio@macos ember-scanner % ./ember-scanner \
        > -listen :80                            \
        > -ssl_auto_cert mydomain.com            \
        > -ssl_listen :443

## Save your advanced configuration to a config file

You don't want to have to type everytime a long list of arguments. No problem, you can save your advanced configuration to a file by adding the **-config_save** argument.

        rdio@macos ember-scanner % ./ember-scanner \
        > -listen :80                            \
        > -ssl_auto_cert mydomain.com            \
        > -ssl_listen :443                       \
        > -config_save
        2022/12/19 08:52:24 ember-scanner.ini file created

All of your parameters passed as arguments to [Ember Scanner](https://github.com/jjcazau/EmberScanner) have been saved to an INI file which has the same arguments/values list.

        db_file = ember-scanner.db
        db_type = sqlite
        listen = :80
        ssl_auto_cert = mydomain.com
        ssl_listen = :443

Then simply run [Ember Scanner](https://github.com/jjcazau/EmberScanner) without any arguments.

        rdio@macos ember-scanner % ./ember-scanner

        Ember Scanner v7.0.0
        ----------------------------------
        2022/12/19 08:54:08 server started
        2022/12/19 08:54:08 main interface at http://macos.local
        2022/12/19 08:54:08 main interface at https://macos.local
        2022/12/19 08:54:08 admin interface at https://macos.local/admin

## Install Ember Scanner as a service

Everything looks ok now, but you do not want to manualy start [Ember Scanner](https://github.com/jjcazau/EmberScanner) after every reboot. No problem, you can install your server instance as a service. **Note that you will be required to proceed in a command prompt that is running as Administrator**.

        rdio@macos ember-scanner % sudo ./ember-scanner -service install
        Password:
        rdio@macos ember-scanner % sudo ./ember-scanner -service start
        rdio@macos ember-scanner % ps ax | grep ember-scanner
        64627   ??  Ss     0:00.13 /Users/radio/ember-scanner/ember-scanner -service run
        64630 s000  S+     0:00.00 grep ember-scanner

## Get the full list of arguments

To get the whole list of arguments you can pass to [Ember Scanner](https://github.com/jjcazau/EmberScanner), simply pass the argument **-h**.

        rdio@macos ember-scanner % ./ember-scanner -h
        Usage of ./ember-scanner:
          -admin_password string
                change admin password
          -base_dir string
                base directory where all data will be written
          -cmd string
                advanced administrative tasks (use -cmd help for usage)
          -config string
                server config file (default "ember-scanner.ini")
          -config_save
                save configuration to ember-scanner.ini
          -db_file string
                sqlite database file (default "ember-scanner.db")
          -db_host string
                database host ip or hostname (default "localhost")
          -db_name string
                database name
          -db_pass string
                database password
          -db_port uint
                database host port (default 3306)
          -db_type string
                database type, one of sqlite, mariadb, mysql, postgresql (default "sqlite")
          -db_user string
                database user name
          -listen string
                listening address (default ":3000")
          -service string
                service command, one of start, stop, restart, install, uninstall
          -ssl_auto_cert string
                domain name for Let's Encrypt automatic certificate
          -ssl_cert_file string
                ssl PEM formated certificate
          -ssl_create
                create self-signed certificates
          -ssl_key_file string
                ssl PEM formated key
          -ssl_listen string
                listening address for ssl
          -version
                show application version
        rdio@macos ember-scanner %
