# Security policy

Security fixes target the latest Ember Scanner release. Older releases may not receive patches.

## Reporting a vulnerability

Do not disclose a vulnerability in a public issue. Use GitHub's private vulnerability reporting for the repository:

https://github.com/jjcazau/EmberScanner/security/advisories/new

Include the affected version, impact, reproduction steps, and any proof of concept that helps verify the report. Please allow reasonable time for investigation and remediation before public disclosure.

This policy covers code and tooling maintained in this repository. Third-party dependencies and external services are outside its scope.
